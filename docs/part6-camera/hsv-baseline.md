# 6-2 まずは色で探す：HSV しきい値（ベースライン）

## ねらい

- HSV のしきい値で、ボール・黄ゴール・青ゴールを見つけられる
- 「見つけた割合」と「当たった割合」で、見つけ方の良さを数字で測れる
- **相手ロボットは色では見つけられない** ことを確かめ、機械学習が必要な理由を説明できる

---

## 理論 1：色のしきい値で探す手順

1. 画像を HSV にする
2. 「H が 5〜22、S が 120 以上、V が 120 以上」のように、色の範囲に入る画素だけを白、それ以外を黒にする（**マスク**）
3. 白い画素のかたまりを探す（**連結成分**）
4. いちばん大きいかたまりの中心を、ボールの位置とする

ボールはオレンジ、ゴールは黄色と青と、**色がルールで決まっている** ので、この方法がよく使われます。

## 理論 2：見つけ方の良さの測り方

3-4 と同じように、2 種類のまちがいを数えます。

| 数 | 意味 |
|---|---|
| **見つけた割合**（再現率） | 写っているボールのうち、ちゃんと見つけた割合 |
| **当たった割合**（適合率） | 「ボールだ」と言ったもののうち、本当にボールだった割合 |

予測した中心が、正解の枠の中（4 ピクセル以内）にあれば「当たり」とします。

## 手を動かす 1：1 枚で試す

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt
from rcjml.sim.camera import make_images, HORIZON, CLASSES
from rcjml.vision import hsv_detect, evaluate, HSV_RANGES

X, labels, _ = make_images(8, seed=1)
img = X[0]
hsv = cv2.cvtColor(img, cv2.COLOR_RGB2HSV)
lo, hi = HSV_RANGES[0][0]                       # ボール（オレンジ）の範囲
mask = cv2.inRange(hsv, np.array(lo, np.uint8), np.array(hi, np.uint8))

fig, axes = plt.subplots(1, 2, figsize=(7, 3.5))
axes[0].imshow(img); axes[0].set_title("image")
axes[1].imshow(mask, cmap="gray"); axes[1].set_title("orange mask")
for d in hsv_detect(img):
    axes[0].plot(d.cx, d.cy, "x", color="white", ms=10, mew=2)
plt.show()
print(HSV_RANGES)
```

## 手を動かす 2：1,000 枚で成績を測る

```python
X, labels, _ = make_images(1000, seed=100)

def show_result(name, preds):
    r = evaluate(preds, labels)
    print(name)
    for cls, v in r.items():
        print(f"  {cls:12s} 見つけた {v['recall']:.0%}  当たった {v['precision']:.0%}  （正解 {v['n_true']} 個）")

show_result("色だけ", [hsv_detect(x) for x in X])
```

| | 見つけた割合 | 当たった割合 |
|---|---|---|
| ボール | 35% | 24% |
| 黄ゴール | 92% | 42% |
| 青ゴール | 91% | 38% |
| ロボット | **0%** | — |

ボールの成績がよくありません。画像を見ると、**コートの外の人の服** や、**ロボットのオレンジの部品** を、ボールとまちがえています。

## 手を動かす 3：探す場所をしぼる

ボールは床の上にしかないので、**地平線より下** だけを探すようにします。ゴールは **地平線のまわり** だけを探します。

```python
show_result("色 ＋ 探す場所をしぼる", [hsv_detect(x, horizon=HORIZON) for x in X])
```

| | 見つけた割合 | 当たった割合 |
|---|---|---|
| ボール | **77%** | **62%** |
| 黄ゴール | 94% | 49% |
| 青ゴール | 96% | 40% |
| ロボット | **0%** | — |

ボールはずいぶん良くなりました。このように、従来の方法も **工夫しだいで良くなります**。でも、

- ゴールは、写っていないときに背景の黄色や青を「ゴール」と言ってしまう（当たった割合が 40〜50%）
- 遠くの小さいボール、ロボットの部品のオレンジには、まだ負ける
- そして **ロボットはまったく見つけられない**

ロボットは、チームごとに形も色もばらばらです。黒いロボット、白いロボット、オレンジの部品がついたロボット……。「この色ならロボット」と決められないので、**色のしきい値では原理的に見つけられません**。ここが、機械学習の出番です。

!!! example "やってみよう"
    1. `rcjml.vision.HSV_RANGES` の値を変えて、ボールの成績がどう変わるか試しましょう（たとえば S の下限を 120 から 160 に）。
    2. `make_images(1000, seed=101, difficulty="hard")` で、照明の変化が大きいときの成績を測りましょう。
    3. 「黒っぽいかたまり（V が小さい）」をロボットとする方法を自分で書いてみましょう。何が問題になるでしょう。

## チェック問題

1. ボールを探す場所を「地平線より下」にしぼると、当たった割合が上がるのはなぜですか。
2. ゴールの「当たった割合」が低いのは、どんなときにまちがえているからですか。
3. 相手ロボットを色のしきい値で見つけられないのはなぜですか。

??? note "答え"
    1. コートの外の人の服など、地平線より上にあるオレンジのものを、最初から探さなくなるからです。
    2. ゴールが写っていないときに、背景の黄色や青のもの（服、看板など）をゴールと言ってしまうからです。
    3. ロボットの色や形がチームごとに違い、「この色ならロボット」という決まりがないからです。黒いロボットを探そうとしても、壁や影も黒いので区別できません。

## つまずきポイント

??? failure "実機の画像で、ボールがまったく見つからない"
    しきい値は会場の照明やカメラで大きく変わります。実際の画像で、ボールの画素の HSV を `print` して確かめ、範囲を合わせます。6-1 の「もっと深く」のとおり、カメラの自動調整も止めておきます。

## もっと深く

!!! deeper "色のしきい値はなくならない"
    機械学習のほうが強いからといって、色のしきい値がいらなくなるわけではありません。

    - 計算がとても軽い（教材の PC で 1 枚 0.3 ms ほど）
    - 何をしているかが全部わかるので、会場で直しやすい

    実際のロボットでは、「ボールとゴールは色で探し、ロボットだけ機械学習で探す」「機械学習の結果を、色で確かめる」のように、**組み合わせて使う** のがよくあるやり方です。
