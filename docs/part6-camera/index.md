# 第6部 カメラ認識：ボール・ゴール・相手ロボット

<span class="ratio">理論 3.5 : 実装 6.5</span>

## ねらい

CoreS3 のカメラで、ボール・黄ゴール・青ゴール・相手ロボットを見つけます。

## この部の章

| 章 | 内容 |
|---|---|
| 6-1 | 画像はただの数字の表：画素、RGB と HSV、解像度とフレームレート |
| 6-2 | 従来手法（HSV しきい値）でボールとゴールを検出。相手ロボットは色では見つけられないことを確かめる |
| 6-3 | 画像を集める：CoreS3 で撮影し、SD か Wi-Fi で PC へ |

| 6-6 | 物体検出：Edge Impulse の FOMO（本線）と ESP-DL / ESP-Detection（発展） |
| 6-7 | CoreS3 で速く動かす：解像度、グレースケール、FPS と遅延 |
| 6-8 | 相手ロボットを見つける：画像の集め方（知り合いのチームに頼む）、データ拡張、誤検出の減らし方 |
| 6-9 | IR とカメラの融合と使い道 |
