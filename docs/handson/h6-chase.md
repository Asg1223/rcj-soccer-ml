# H6 ボールを追いかける

| 時間の目安 | 本文 | 使う機材 |
|---|---|---|
| 90〜120 分 | [5-5](../part5-two-boards/control.md) | ロボット全体（センサ側、CoreS3、モータ側、モータドライバ、バッテリー）、IR ボール、広い床 |

## ゴール

- BallNet の推定を使って、ロボットが **ボールの後ろに回りこんで** 取りに行く
- データが来なくなったら **必ず止まる** ことを確かめる
- 成功率と、取るまでの時間を測る

---

## ステップ

### 1. シミュレータで動きを確かめる（15 分）

- [ ] 5-5 の「手を動かす 1」を動かし、ボールが真後ろにあるとき、まっすぐ向かわずに回りこむことを図で見た

### 2. 書き込みと配線（25 分）

- [ ] モータ側に `firmware/motor-arduino/motor_receiver` を書き込んだ。ピンを自分の機体に合わせた
- [ ] `firmware/cores3/ball_chase` をチーム用リポジトリにコピーし、モデルとヘッダを書き出して書き込んだ。`WHEEL_DEG`（タイヤの位置）を自分の機体に合わせた
- [ ] `MAX_SPEED` を **300** にした（最初は小さく）
- [ ] 配線：センサ側 → CoreS3 の Port C、CoreS3 の Port B → モータ側

### 3. タイヤを浮かせて確かめる（20 分）

- [ ] ロボットを台にのせて、**タイヤを床から浮かせた**
- [ ] 画面をタッチして動かし、ボールを正面に置くと、4 輪が **前に進む向き** に回った。逆に回るタイヤは `SIGN` を -1 にした
- [ ] ボールを左（+90°）に置くと、左に進む向きに回った
- [ ] もう一度タッチすると止まった
- [ ] **センサ側の電源を抜くと、0.2 秒以内にモータが止まった**（CoreS3 は 100 ms、モータ側は 200 ms で止まる）
- [ ] **CoreS3 の電源を抜くと、モータが止まった**

!!! warning "止まる確認が終わるまで床に置かない"
    最後の 2 つは、ロボットが暴走しないための大事な確認です。ここで止まらないなら、床に置かずに `motor_receiver` と配線を見直します。

### 4. 床で走らせる（30 分）

- [ ] ロボットを床に置き、ボールを正面 50 cm に置いて取りに行けた
- [ ] 次の 4 つの位置から **各 5 回**、取りに行けたかと、かかった時間を記録した

| 位置 | ボールの場所（ロボットから見て） |
|---|---|
| A | 正面、100 cm |
| B | 左、50 cm |
| C | 右後ろ（-135°）、50 cm |
| D | 真後ろ、30 cm |

「取れた」は、ボールがキャッチャーに入った（または前に押せた）ときとします。30 秒以内に取れなければ失敗です。

### 5. 1 つだけ調整する（20 分）

結果を見て、次のうち **1 つ** を変えて、もう一度測ります。

- [ ] `MAX_SPEED` を上げる（300 → 450 → 600）
- [ ] 回りこみの強さ（`chaseDirection` の中の 40 cm や 0.3）を変える
- [ ] 近いときの減速（25 cm、0.7）を変える

---

## 合格条件

- [ ] センサ側・CoreS3 のどちらの電源を抜いても、モータが止まる
- [ ] A〜D の 20 回のうち **15 回以上** 取れた
- [ ] 真後ろ（D）で、ボールを押し出さずに回りこめた回数を記録した
- [ ] 調整の前と後の数字を記録した

## 困ったとき

??? failure "ボールの周りをぐるぐる回る"
    回りこみが強すぎるか、角度の推定が大きく揺れています。回りこみの強さを下げるか、H9 の追跡（7-4 の α-β フィルタ）を入れます。CoreS3 の画面で、推定の角度が揺れていないか見ます。

??? failure "正面のボールに向かって斜めに進む"
    `WHEEL_DEG` の順番と、モータ側のピンの順番が合っていません。1 輪ずつ回して、どのタイヤが何番か確かめます。

??? failure "モータを回すと `crc` が増える"
    モータの電気のノイズです。センサ・通信の線をモータの線から離す、モータにコンデンサを付ける、電源を分ける、を試します。

??? failure "真後ろのボールを押し出してしまう"
    近いときに回りこむ量が足りません。真後ろのとき、横に大きく回ってから後ろに回るように、回りこみの強さを上げます。

## 発展課題

- ボールを手で転がして動かしたときも、追いかけられるか試す
- 回転（`omni4` の `rotation`）を使って、いつも相手ゴールの方を向いたまま追いかける（ジャイロ・コンパスが必要）
