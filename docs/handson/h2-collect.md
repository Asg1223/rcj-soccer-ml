| 時間の目安 | 本文 | 使う機材 |
|---|---|---|
| 150 分（2〜3 回に分けてよい） | [1-4](../part1-ir-data/labels.md)、[1-5](../part1-ir-data/explore.md)、（CoreS3 で集めるなら [5-4](../part5-two-boards/collect.md)） | PC、センサ側マイコン、IR ボール、床の目印 |

## ゴール

- 自分のロボットの IR データを、**取り直し（セッション）3 回分** 集める
- 集めたデータを図にして、おかしなところがないか確かめる

取り直し 3 回のうち、2 回を学習に、1 回をテストに使います（H3）。**3 回は、日や時間、部屋の明るさを変えて** 集めると、本番に強いデータになります。

---

## ステップ

### 1. 床に目印を付ける（20 分）

- [ ] ロボットの中心を置く場所に印を付け、0°（正面）・90°（左）・180°・-90°（右）の線をテープで貼った
- [ ] 10, 20, 30, 45, 60, 80, 100, 130 cm の距離に印を付けた
- [ ] ロボットの「正面」がどちらかを決めて、ロボットにも印を付けた（角度は **正面 0°、左が +** ／1-4）

### 2. 練習（10 分）

- [ ] シミュレータで、手順に慣れた

```bash
python -m rcjml.logger plan --session 1 --port sim --allow-public --limit 10
```

### 3. 本番：取り直し 1 回目（50 分）

- [ ] 部屋の様子をメモした（照明、窓のカーテン、時刻）
- [ ] ボールの電池を確かめた（取り直しごとに同じ状態で始める）
- [ ] 実機で集めた

```bash
python -m rcjml.logger plan --session 1
```

保存先は `robot.yaml` の `data.dir`（チーム用リポジトリの `data/ir/`）です。疲れたら `q` で止めて、同じ `--session 1` で続きから集めてかまいません。

### 4. 取り直し 2 回目・3 回目

- [ ] **別の日、別の時間、または照明を変えて** `--session 2` を集めた
- [ ] 同じように `--session 3` を集めた

!!! tip "CoreS3 で集めるとき"
    5-4 のデータ収集モード（`firmware/cores3/collect`）を使うと、PC を床に置かずに、コートの上で集められます。H5 が終わってから使えます。

### 5. データを眺める（20 分）

チーム用リポジトリの `notebooks/` に新しいノートブックを作り、1-5 と同じように図にします。

```python
import matplotlib.pyplot as plt
from rcjml import load_config
from rcjml.data import load_log, sensor_columns
from rcjml.plot import polar_grid

cfg = load_config()
df = load_log(cfg, "ir_log.csv")
S = sensor_columns(df)
print(df.groupby("session").size())           # 取り直しごとの行数
print(df[S].describe().T[["min", "max"]])     # センサごとの最小・最大

# 取り直し 1 回目から、30° ごとに「30 cm にいちばん近い」行を 1 つずつ選んで描く
pick = (df[(df.session == df.session.min()) & (df.has_ball == 0)]
        .assign(bin=lambda d: d.angle_deg // 30, gap=lambda d: (d.distance_cm - 30).abs())
        .sort_values("gap").groupby("bin").head(1).sort_values("angle_deg"))
polar_grid(cfg, pick[S].values, titles=[f"{a:+.0f}°" for a in pick.angle_deg],
           true_angles=pick.angle_deg.values)
plt.show()
```

- [ ] 取り直しごとの行数が、だいたいそろっている
- [ ] 角度ごとの図で、ボールの方向のセンサがいちばん大きい
- [ ] 1 つだけ形がおかしい角度・距離がないか確かめた（あれば、その位置を集め直した）

## 困ったとき

??? failure "保存しようとすると止まる"
    教材のロガーには、例の設定のままのときや、保存先が教材のリポジトリの中のときに保存しない安全装置があります（1-4）。`RCJML_CONFIG` がチーム用の `robot.yaml` を指しているか確かめます。

??? failure "集めるのに時間がかかりすぎる"
    1 回目は `--limit 100` で短くしてもかまいません。ただし、3 回ともだいたい同じ数にします。回転台でロボットを回す方法（1-4 の発展）もあります。

??? failure "角度の図で、ボールと反対側のセンサも大きい"
    かべや机の脚で、赤外線が反射しています。周りに物がない場所で集めます。本番のコートにはかべがあるので、コートで集めるときは、反射も「本番の一部」として入れてかまいません。

## 発展課題

- 取り直し 1 回目と 3 回目で、同じ位置（正面 30 cm など）の値を比べる。どれくらい違うでしょう
- ボールを保持した状態（キャッチャーに入れた状態）のデータを、多めに集めておく（H3 の保持の判定に使います）
