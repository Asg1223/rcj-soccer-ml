# H1 動作確認：センサの値を PC で見る

| 時間の目安 | 本文 | 使う機材 |
|---|---|---|
| 90 分 | [0-2](../part0-setup/environment.md)、[0-4](../part0-setup/config.md)、[1-2](../part1-ir-data/read-sensors.md)、[1-3](../part1-ir-data/send-to-pc.md) | PC、センサ側マイコン、CoreS3、IR ボール |

## ゴール

- PC で教材のコードが動く
- センサ側マイコンと CoreS3 に、スケッチを書き込める
- **全部のセンサ** がボールに反応していることを、PC の画面で確かめる

---

## ステップ

### 1. PC の準備（30 分）

- [ ] 0-2 の手順で Python 3.12 の仮想環境を作り、`pip install -r requirements.txt` と `pip install -e .` を実行した
- [ ] `notebooks/00_check_environment.ipynb` を VS Code で開き、全部のセルが最後まで動いた
- [ ] チーム用リポジトリの `configs/robot.yaml` に、自分の機体のセンサの数と取り付け角度を書いた（0-4）
- [ ] 環境変数 `RCJML_CONFIG` にその場所を入れ、次の結果が自分の機体の値になった

```bash
python -c "from rcjml import load_config; from rcjml.config import describe; print(describe(load_config()))"
```

### 2. マイコンの準備（20 分）

- [ ] センサ側マイコンに `firmware/check/serial_hello` を書き込み、シリアルモニタ（115200 bps）に文字が出た
- [ ] CoreS3 に `firmware/check/cores3_hello` を書き込み、画面に文字が出た

### 3. センサの値を見る（40 分）

- [ ] センサ側マイコンに `firmware/sensor-arduino/ir_ring_reader`（ESP32 なら `sensor-esp32/ir_ring_reader`）を書き込んだ。スケッチの設定部分で、センサの数とピン番号を自分の機体に合わせた
- [ ] シリアルモニタを **閉じてから**、PC で値を見た

```bash
python -m rcjml.logger monitor --port COM3      # Mac は /dev/cu.usbmodem... など
```

- [ ] ボールをロボットの周りで **ゆっくり 1 周** させ、いちばん大きな値のセンサが順番に移っていくのを確かめた
- [ ] ボールを近づけたり遠ざけたりして、値が変わるのを確かめた
- [ ] ボールの電源を切ると、ほとんどのセンサが 0 近くになるのを確かめた

---

## 合格条件

- [ ] `00_check_environment.ipynb` が最後まで動く
- [ ] 全部のセンサが、ボールを正面に向けたときに反応する（反応しないセンサが 0 個）
- [ ] ボールを 1 周させたとき、反応するセンサが **飛ばずに** 隣へ移っていく（取り付け角度の順番と、配線の順番が合っている）

## 困ったとき

??? failure "ポートが見つからない、開けない"
    シリアルモニタや、ほかのプログラムがポートを使っていると開けません。全部閉じます。ケーブルが充電専用のこともあります。別のケーブルで試します。

??? failure "1 周させたとき、反応するセンサが飛ぶ"
    配線の順番と、`robot.yaml` やスケッチのピンの順番が合っていません。1 個ずつボールを当てて、何番のセンサが反応するかを表にします。

??? failure "どのセンサもいつも大きな値"
    窓からの日光や照明に、赤外線が多く含まれています。カーテンを閉めるか、場所を変えます。ボールの電源を切って値を見ると、外乱光の大きさがわかります。
