# H7 画像を集めてラベルを付ける

| 時間の目安 | 本文 | 使う機材 |
|---|---|---|
| 150 分（2〜3 回に分けてよい） | [6-1](../part6-camera/pixels.md)、[6-2](../part6-camera/hsv-baseline.md)、[6-3](../part6-camera/collect-images.md)、[6-4](../part6-camera/labeling.md) | PC、CoreS3（ロボットに付けた状態）、microSD、ボール、黄・青のゴール、ほかのロボット |

## ゴール

- **ロボットに付けた CoreS3** で、本番と同じ高さ・向きの画像を集める
- 4 種類（ボール・黄ゴール・青ゴール・ロボット）にラベルを付けて、YOLO 形式で保存する
- 撮影ごとにフォルダを分けて、H8 で「撮影で分けた評価」ができるようにする

---

## ステップ

### 1. 撮影の準備（15 分）

- [ ] CoreS3 を **本番と同じ位置・向き** でロボットに取り付けた
- [ ] microSD を FAT32 でフォーマットし、CoreS3 に入れた
- [ ] `firmware/cores3/camera_capture` を書き込み、画面に `SD ok` と出た
- [ ] 6-2 の HSV のノートブックで、自分のボールとゴールの色の範囲をだいたい確かめた（照明で色がどう変わるかの見当をつける）

### 2. 1 回目の撮影（30 分）

チーム用リポジトリに `data/camera/<日付_場所>/` のフォルダを作り、そこに入れていきます（例：`data/camera/2026-11-20_bukatsu/`）。

- [ ] ボールを、**近く・遠く・左右の端・ゴールの前・ロボットの陰** に置いて撮った
- [ ] 黄ゴール・青ゴールを、正面・ななめ・遠くから撮った
- [ ] ほかのロボットを、前後左右から撮った（自分のチームの別の機体でもよい）
- [ ] 何も写っていない（床やかべだけの）画像も 1 割くらい撮った
- [ ] 合わせて **200 枚以上** になった

!!! private "ほかのチームのロボット"
    ほかのチームのロボットを撮るときは、**必ず先に許可をもらいます**。画像はチーム用リポジトリ（非公開）だけに置き、頼まれたらすぐに消します（6-8）。

### 3. ラベルを付ける（60 分）

- [ ] [makesense.ai](https://www.makesense.ai/) で、画像をブラウザに読み込んだ（画像はサーバーに送られない）
- [ ] ラベルの名前を **ball, yellow_goal, blue_goal, robot の順** で作った
- [ ] 枠の付け方のルールを決めて、記録シートに書いた（半分隠れた物にも付ける？ 画面の端で切れた物は？）
- [ ] 全部の画像に枠を付け、**YOLO 形式** で書き出して、画像と同じフォルダに `.txt` を置いた

### 4. 読み込んで確かめる（20 分）

```python
from collections import Counter
from rcjml import load_config
from rcjml.vision import load_yolo_folder
from rcjml.sim.camera import CLASSES

cfg = load_config()
team = cfg.source.parent.parent
X, labels, sessions = load_yolo_folder(team / "data" / "camera",
                                       class_names=["ball", "yellow_goal", "blue_goal", "robot"])
print(X.shape, sorted(set(sessions)))
count = Counter(CLASSES[b.cls] for boxes in labels for b in boxes)
print("種類ごとの数:", dict(count))
print("何も写っていない画像:", sum(len(b) == 0 for b in labels), "枚")
```

- [ ] 種類ごとの数を記録シートに書いた
- [ ] 6-4 の方法で、何枚か枠を重ねて表示し、ずれていないことを確かめた

### 5. 2 回目の撮影（30 分）

- [ ] **別の日・別の場所・別の照明** で、もう 1 フォルダ分（100 枚以上）撮って、ラベルを付けた。H8 ではこれをテストに使う

## 困ったとき

??? failure "`load_yolo_folder` でラベルが 0 個になる"
    `.txt` が画像と同じフォルダ・同じ名前になっているか確かめます。makesense.ai で書き出すと zip になるので、展開して画像の横に置きます。

??? failure "種類がずれて読み込まれる（ボールがロボットになる）"
    ラベルを作った順番が違います。`class_names` に、ツールで作った順番をそのまま渡します（6-4）。

??? failure "画像が暗い・ぶれる"
    CoreS3 のカメラは暗いところが苦手です。部屋を明るくするか、ロボットを止めて撮ります。本番の照明に近い場所で撮るのがいちばんです。

## 発展課題

- 6-2 の HSV のしきい値で、自分の画像のボールとゴールをどれくらい見つけられるか測る（H8 で比べる相手になります）
- 2 人で同じ 20 枚にラベルを付けて、枠のずれを比べる
