# 第1部 IR データを集める

<span class="ratio">理論 3 : 実装 7</span>

## ねらい

IR センサリングの値を読み、正解（ボールの角度・距離）をつけて PC に保存できるようになります。

## この部の章

| 章 | 内容 |
|---|---|
| 1-1 | IR ボールとセンサの仕組み（変調、パルス幅、受光センサの特性） |
| 1-2 | センサリングの値を読む：Arduino / ESP32 スケッチ、パルス幅を強さに変換 |
| 1-3 | PC に送る：シリアル通信、Python ロガー、CSV 保存（保存先はチーム用リポジトリ） |
| 1-4 | 正解ラベルをつける：角度・距離を印刷したマット、サーボ回転台で自動収集 |
| 1-5 | データを眺める：極座標プロット、ヒートマップ、外れ値探し |
