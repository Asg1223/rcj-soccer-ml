# 3-4 分類：ボールを保持しているか

## ねらい

- 「はい・いいえ」を当てる **分類** の考え方（確率、しきい値）がわかる
- **混同行列** で、どんな間違いをしているかを数えられる
- ロボットの使い方に合わせて、しきい値を決められる

---

## 理論 1：分類は「確率」を出してから決める

ボールを保持しているかは、角度や距離のような「数の大きさ」ではなく、**はい（1）か いいえ（0）** の答えです。こういう問題を **分類** といいます。

BallNet は、いきなり「はい・いいえ」を出すのではなく、まず **保持している確率**（0〜1）を出します。そのあと、

$$
\text{確率} > \text{しきい値} \quad\Rightarrow\quad \text{保持している}
$$

と決めます。しきい値はふつう 0.5 ですが、使い方に合わせて変えられます。

確率は、ネットの出力 $z$（ロジット）を **シグモイド関数** に通して作ります。

$$
p = \frac{1}{1 + e^{-z}}
$$

$z$ が大きいほど 1 に、小さいほど 0 に近づきます。

## 理論 2：交差エントロピー

分類の損失には **交差エントロピー** を使います。

$$
L = -\big( y \log p + (1 - y) \log (1 - p) \big)
$$

正解が 1 のときは $-\log p$、正解が 0 のときは $-\log(1 - p)$ です。**自信満々にまちがえる**（正解が 1 なのに $p = 0.01$）と、損失がとても大きくなります。だから、ネットは「わからないときは 0.5 くらいにしておく」ことを学びます。

## 理論 3：正解率だけ見てはいけない

合成データでは、保持しているデータは全体の 8% くらいしかありません。すると、**いつも「保持していない」と答える** だけで、正解率は 92% になってしまいます。

そこで、間違いを種類に分けて数えます。これを **混同行列** といいます。

| | 予測：保持している | 予測：していない |
|---|---|---|
| **本当に保持している** | 正しく見つけた（TP） | **見のがした**（FN） |
| **本当はしていない** | **空振り**（FP） | 正しく「ない」と言えた（TN） |

- **見つけた割合（再現率）** ＝ TP ÷（TP ＋ FN）：保持しているときに、ちゃんと「保持」と言えた割合
- **空振りの割合** ＝ FP ÷（FP ＋ TN）：保持していないのに「保持」と言ってしまった割合

ロボットでは、この2つのどちらが困るかを考えて、しきい値を決めます。

| まちがい | ロボットで起きること |
|---|---|
| 見のがし | ボールを持っているのに、まだ追いかけようとする。シュートが遅れる |
| 空振り | ボールを持っていないのに、シュートの動作に入る。キッカーが空振りする |

## 手を動かす 1：3-2 のモデルで確率を出す

3-2 の続きです（ノートブックでは続けて実行します）。

```python
p_hold = decode(P)["p_hold"]
true_hold = test["has_ball"].values == 1
print("保持しているデータの割合:", true_hold.mean().round(3))

plt.hist(p_hold[~true_hold], bins=50, alpha=0.6, label="not holding")
plt.hist(p_hold[true_hold], bins=50, alpha=0.6, label="holding")
plt.yscale("log")
plt.xlabel("predicted probability of holding")
plt.legend()
plt.show()
```

保持しているデータ（橙）は右（1 に近い）、していないデータ（青）は左（0 に近い）に集まっていれば、うまく見分けられています。

## 手を動かす 2：混同行列を作る

```python
def confusion(true, pred):
    return pd.DataFrame(
        [[(true & pred).sum(), (true & ~pred).sum()],
         [(~true & pred).sum(), (~true & ~pred).sum()]],
        index=["true: holding", "true: not"], columns=["pred: holding", "pred: not"],
    )

pred = p_hold > 0.5
print(confusion(true_hold, pred))
print("見つけた割合:", (pred[true_hold]).mean().round(3))
print("空振りの割合:", (pred[~true_hold]).mean().round(4))
```

## 手を動かす 3：しきい値を動かす

```python
rows = []
for th in [0.1, 0.3, 0.5, 0.7, 0.9, 0.97]:
    pred = p_hold > th
    rows.append({"threshold": th,
                 "recall": pred[true_hold].mean(),
                 "false alarm": pred[~true_hold].mean()})
pd.DataFrame(rows).round(4)
```

しきい値を **上げる** と、空振りは減りますが、見のがしが増えます。**下げる** と逆です。両方を同時に減らすことはできないので、「どちらがより困るか」で決めます。

!!! tip "ロボットでのしきい値の決め方の例"
    - シュートの動作に入るとき：空振りを減らしたいので、しきい値を **高め**（例：0.9）
    - 「ボールを持ったかもしれないから、ゆっくり回りこむ」：見のがしを減らしたいので **低め**（例：0.3）

    1つのモデルの確率を、場面ごとに違うしきい値で使い分けることもできます。

!!! example "やってみよう"
    1. `hard` のデータでは、見つけた割合と空振りの割合はどうなるでしょう。
    2. 保持の判定を、距離の推定（`decode(P)["distance_cm"] < 8`）だけで代わりにすると、どれくらい当たるでしょう。BallNet の確率と比べましょう。

## チェック問題

1. 保持しているデータが全体の 5% しかないとき、「いつも保持していない」と答えるモデルの正解率は何%ですか。そのモデルの「見つけた割合」はいくつですか。
2. しきい値を 0.5 から 0.9 に上げると、空振りと見のがしはそれぞれどうなりますか。
3. ネットが、正解が 1 のデータに $p = 0.5$ と答えたときと、$p = 0.01$ と答えたときでは、どちらの損失が大きいですか。

??? note "答え"
    1. 正解率 95%、見つけた割合は 0% です。正解率だけでは良いモデルに見えてしまいます。
    2. 空振りは減り（または同じ）、見のがしは増えます（または同じ）。
    3. $p = 0.01$ のほうです（$-\log 0.5 \approx 0.69$、$-\log 0.01 \approx 4.6$）。

## つまずきポイント

??? failure "保持の確率がいつも 0 近くになる"
    保持しているデータが少なすぎるか、ないかもしれません。`train["has_ball"].mean()` を確かめます。実機のデータを集めるときは、1-4 の `plan` で保持の位置も記録されます。

## もっと深く

!!! deeper "少ない側のデータを大事にする方法"
    片方の答えがとても少ないデータを **不均衡データ** といいます。対策には、

    - 損失で、少ない側の重みを大きくする（`keras_loss(hold_weight=...)` や、Keras の `class_weight`）
    - 少ない側のデータを複製して増やす（オーバーサンプリング）
    - 評価に、正解率ではなく **PR 曲線**（しきい値を動かしたときの「見つけた割合」と「当たった割合」の関係）や **F1 スコア** を使う

    などがあります。どれを使っても、最後にしきい値をロボットの使い方に合わせて決めることが大事なのは同じです。
