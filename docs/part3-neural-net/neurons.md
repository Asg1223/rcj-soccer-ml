# 3-1 ニューロンと層

## ねらい

- ニューラルネットの「ニューロン」「層」「活性化関数」が何をしているか説明できる
- NumPy だけで、小さなニューラルネットの計算（推論）を書ける
- なぜ ReLU を入れると「場合分け」ができるのかがわかる

---

## 理論 1：ニューロンは「線形モデル＋ひとひねり」

ニューロン1個の計算は、2-2 の線形モデルとほとんど同じです。

$$
h = \mathrm{ReLU}(w_0 x_0 + w_1 x_1 + \cdots + b)
$$

違うのは最後の **ReLU** だけです。ReLU は「マイナスなら 0、プラスならそのまま」という、とても簡単な関数です。

$$
\mathrm{ReLU}(z) = \max(0, z)
$$

このような、ニューロンの最後にかける関数を **活性化関数** といいます。

## 理論 2：ニューロンを並べたものが「層」

ニューロンを何個か横に並べて、同じ入力をそれぞれに入れたものを **層** といいます。層の出力を、次の層の入力にします。

```mermaid
flowchart LR
  X["入力<br>センサ 12 個"] --> H1["隠れ層 1<br>ニューロン 64 個"]
  H1 --> H2["隠れ層 2<br>ニューロン 64 個"]
  H2 --> Y["出力層<br>4 個"]
```

- **入力層**：センサの値（12 個）
- **隠れ層**：途中の層。外からは見えない
- **出力層**：答え。この教材では 4 個（cos、sin、距離、保持）

全部のニューロンが前の層の全部とつながっている形を **全結合層**（Dense 層）といい、全結合層を重ねたネットを **MLP**（多層パーセプトロン）といいます。

## 理論 3：なぜ ReLU で「場合分け」ができるのか

ReLU がないと、線形モデルを何層重ねても、計算をまとめると **1つの線形モデル** になってしまいます（かけて足したものを、またかけて足しても、かけて足しただけ）。

ReLU があると、ニューロンごとに「この条件のときだけ働く」という **スイッチ** ができます。たとえば

- 「後ろのセンサが強いときだけ働くニューロン」
- 「全体が暗い（ボールが遠い）ときだけ働くニューロン」

のように、いろいろな場合を受け持つニューロンができ、それを組み合わせて答えを出せるのです。2-2 で線形回帰が苦手だった「場合分け」が、これでできるようになります。

## 手を動かす 1：ReLU と 1 個のニューロン

```python
import numpy as np
import matplotlib.pyplot as plt

def relu(z):
    return np.maximum(0, z)

z = np.linspace(-3, 3, 100)
plt.plot(z, relu(z))
plt.xlabel("z")
plt.ylabel("ReLU(z)")
plt.show()

# 入力 3 個、ニューロン 1 個
x = np.array([0.8, 0.1, 0.0])       # センサ 3 個の値（0〜1）
w = np.array([1.0, -2.0, 0.5])      # 重み
b = -0.3                            # バイアス
print("ニューロンの出力:", relu(x @ w + b))
```

## 手を動かす 2：層を自分で書く

全結合層は「行列の掛け算 ＋ バイアス ＋ 活性化関数」です。2-2 で書いた計算と同じ形です。

```python
def dense(x, W, b, activation=None):
    z = x @ W + b
    return relu(z) if activation == "relu" else z

rng = np.random.default_rng(0)
W1, b1 = rng.normal(0, 0.5, (12, 64)), np.zeros(64)    # 入力 12 → 64
W2, b2 = rng.normal(0, 0.2, (64, 64)), np.zeros(64)    # 64 → 64
W3, b3 = rng.normal(0, 0.2, (64, 4)), np.zeros(4)      # 64 → 出力 4

x = rng.random((5, 12))                 # センサの値 5 行分（でたらめ）
h1 = dense(x, W1, b1, "relu")
h2 = dense(h1, W2, b2, "relu")
y = dense(h2, W3, b3)
print(h1.shape, h2.shape, y.shape)      # (5, 64) (5, 64) (5, 4)
print("0 になったニューロンの割合（隠れ層1）:", (h1 == 0).mean().round(2))
```

重みはまだでたらめなので、出力に意味はありません。**学習** とは、この重みを、2-2 と同じく勾配降下法で少しずつ直していくことです。

## 手を動かす 3：重みの数を数える

```python
n_params = W1.size + b1.size + W2.size + b2.size + W3.size + b3.size
print("重みとバイアスの数:", n_params)
print("float（4 バイト）で保存すると:", n_params * 4 / 1024, "KB")
```

この大きさのネット（12 → 64 → 64 → 4）は、**5,252 個**、約 **20.5 KB** です。2-5 のランダムフォレスト（約 90 MB）と比べると、4,000 分の 1 以下です。これなら、マイコンにも載せられそうです（第4部）。

!!! example "やってみよう"
    1. 隠れ層のニューロンを 64 個から 16 個にすると、重みの数はいくつになりますか。
    2. `relu` を使わずに3層重ねた計算 `x @ W1 @ W2 @ W3` と、1つの行列 `W1 @ W2 @ W3` をかけた計算が同じになることを確かめましょう（バイアスは 0 として）。

## チェック問題

1. ReLU(-2.5) と ReLU(1.5) はいくつですか。
2. 活性化関数のない層を何層重ねても、線形モデルと同じになるのはなぜですか。
3. 入力 12 個、隠れ層 32 個 1 層、出力 4 個のネットの、重みとバイアスの数はいくつですか。

??? note "答え"
    1. 0 と 1.5 です。
    2. 「かけて足す」を何回くり返しても、まとめると「かけて足す」1回で書けるからです（行列の掛け算はまとめられる）。
    3. 12 × 32 + 32 + 32 × 4 + 4 = 548 個です。

## つまずきポイント

??? failure "`ValueError: matmul: ... mismatch` と出る"
    層と層で、前の層の出力の数と次の層の入力の数が合っていません。`W1` が (12, 64) なら `W2` は (64, ?) にします。

## もっと深く

!!! deeper "なぜ「ニューラル」ネットと呼ぶのか、なぜ ReLU なのか"
    ニューロン（神経細胞）が、ほかのニューロンからの信号を重みづけして足し、ある程度を超えると信号を出す、という仕組みをまねたのが始まりなので、この名前があります。ただし、今のニューラルネットは脳のしくみとはかなり違います。

    活性化関数には、昔はシグモイド関数 $1/(1+e^{-z})$ がよく使われました。でもシグモイドは $z$ が大きいと傾きがほぼ 0 になり、層を重ねると勾配降下法で重みがほとんど動かなくなる（**勾配消失**）という問題がありました。ReLU はプラス側の傾きがいつも 1 なので、この問題が起きにくく、しかも計算がとても軽い（マイコン向き）ので、今はこちらが標準です。

    十分な数のニューロンがあれば、1 層の隠れ層でも、どんな滑らかな関数でもいくらでも近くまねできる、ということが数学的に証明されています（**万能近似定理**）。ただし「必要なニューロンの数」や「学習でその重みを見つけられるか」は別の話です。
